================================================================================
  QUICK DEPLOY (5 minutes)
================================================================================

STEP 1: Open Render Dashboard
  → https://dashboard.render.com

STEP 2: Create Web Service
  Click "New +" → "Web Service"
  Connect GitHub → lucasmarinskiba/SellIA

STEP 3: Configure
  Name:                  selliaai-backend
  Root Directory:        backend
  Build Command:         pip install -r requirements.txt
  Start Command:         uvicorn app.sellbot:app --host 0.0.0.0 --port 8000
  Region:                North America

STEP 4: Environment Variables
  ALLOWED_ORIGINS = http://localhost:3000,https://sellia-brain.vercel.app
  ENVIRONMENT = production

STEP 5: Create Web Service
  Click button → Wait 5-10 minutes
  Backend URL: https://selliaai-backend.onrender.com

================================================================================
  UPDATE FRONTEND
================================================================================

1. Edit: frontend/.env.production
   Add: NEXT_PUBLIC_API_URL=https://selliaai-backend.onrender.com

2. Redeploy to Vercel
   cd frontend && vercel --prod

3. Test
   Frontend:  https://sellia-brain.vercel.app/sellia-brain
   Backend:   https://selliaai-backend.onrender.com/api/health
   Create:    POST /api/v1/leads/

================================================================================
  API ENDPOINTS
================================================================================

Health & Monitoring:
  GET /api/ping                              - Simple health check
  GET /api/health                            - Detailed status
  GET /api/version                           - Version info
  GET /api/queue/dlq                         - Dead letter queue

Leads:
  POST /api/v1/leads/                        - Create
  GET /api/v1/leads/                         - List (paginated)
  GET /api/v1/leads/{id}                     - Get details
  PUT /api/v1/leads/{id}                     - Update
  DELETE /api/v1/leads/{id}                  - Soft delete
  POST /api/v1/leads/{id}/contact            - Mark contacted
  POST /api/v1/leads/{id}/score              - Rescore
  GET /api/v1/leads/stats/summary            - Statistics

Workflows:
  POST /api/v1/workflows/                    - Create
  GET /api/v1/workflows/                     - List (paginated)
  POST /api/v1/workflows/{id}/activate       - Activate
  POST /api/v1/workflows/{id}/enroll-lead    - Enroll lead

Webhooks:
  POST /api/v1/webhooks/sendgrid             - Email tracking (HMAC verified)
