# DNS Configuration for sellia.io

## Overview
Configure domain DNS records to enable:
- Website hosting (Vercel)
- Email service (Resend)
- Email authentication (SPF, DKIM, DMARC)

## Domain Registrar Access
Log in to your domain registrar:
- GoDaddy
- Namecheap
- AWS Route53
- Cloudflare
- Other registrar

## Required DNS Records

### 1. Website - A Record
```
Type: A
Name: @ (or sellia.io)
Value: 76.76.19.165 (or latest Vercel IP)
TTL: 3600
```
**Purpose:** Routes sellia.io to Vercel frontend

### 2. Website - CNAME Record (www)
```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
TTL: 3600
```
**Purpose:** Routes www.sellia.io to Vercel

### 3. Email - MX Record
```
Type: MX
Name: @ (or sellia.io)
Priority: 10
Value: mx.resend.com
TTL: 3600
```
**Purpose:** Routes emails to Resend

### 4. Email Authentication - SPF
```
Type: TXT
Name: @ (or sellia.io)
Value: v=spf1 include:resend.com ~all
TTL: 3600
```
**Purpose:** Authorizes Resend to send emails from sellia.io

### 5. Email Authentication - DKIM
```
Type: CNAME
Name: default._domainkey
Value: [Generated by Resend - see step 6]
TTL: 3600
```
**Purpose:** Signs emails with DKIM

### 6. Email Authentication - DMARC
```
Type: TXT
Name: _dmarc
Value: v=DMARC1; p=reject; rua=mailto:admin@sellia.io; ruf=mailto:admin@sellia.io; fo=1
TTL: 3600
```
**Purpose:** Sets email policy for domain

### 7. Resend Verification - CNAME
```
Type: CNAME
Name: resend._domainkey
Value: [Generated by Resend - see below]
TTL: 3600
```
**Purpose:** Verifies domain with Resend

## Step-by-Step Configuration

### Step 1: Verify Domain in Resend
1. Log in to Resend dashboard (https://resend.com)
2. Go to Domains section
3. Click "Add Domain"
4. Enter: sellia.io
5. Resend will generate DKIM and verification records

### Step 2: Add Records to DNS Registrar
1. Go to your domain registrar's DNS management page
2. Add each record above
3. Copy exact values from Resend for DKIM records
4. Set TTL to 3600 (1 hour) for faster propagation

### Step 3: Verify in Resend
1. Click "Verify Domain" in Resend
2. Wait for DNS propagation (typically 15-30 mins)
3. Resend will show green checkmarks when verified

### Step 4: Test Email Sending
```bash
curl -X POST "https://api.resend.com/emails" \
  -H "Authorization: Bearer $RESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "test@sellia.io",
    "to": "admin@sellia.io",
    "subject": "DNS Test",
    "html": "<p>If you see this, DNS is configured correctly!</p>"
  }'
```

### Step 5: Test Website
- Visit: https://sellia.io
- Visit: https://www.sellia.io
- Should display Vercel frontend

## Troubleshooting

### DNS not propagating
- Wait 15-30 minutes
- Clear browser cache
- Try incognito/private mode
- Use online DNS checker: https://mxtoolbox.com

### Emails not sending
- Verify DKIM record is added
- Verify SPF record is correct
- Check DMARC policy (p=reject is strict)
- Test with SPF validator: https://mxtoolbox.com/spf.aspx

### Website not loading
- Verify A record is correct
- Verify CNAME for www is correct
- Check Vercel project settings
- Verify domain is added to Vercel project
